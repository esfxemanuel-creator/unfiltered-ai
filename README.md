# UNFILTERED AI — protótipo React

## Rodar localmente

1. Instale Node.js (versão LTS).
2. Abra um terminal nesta pasta.
3. Execute `npm install`.
4. Execute `npm run dev` e abra o endereço local mostrado no terminal.
5. Para testar a compilação, execute `npm run build`.

## Publicar na Vercel

1. Envie esta pasta para um repositório GitHub.
2. Entre em https://vercel.com/new e importe o repositório.
3. A Vercel deve detectar Vite automaticamente.
4. Use `npm run build` como Build Command e `dist` como Output Directory.
5. Clique em Deploy.
6. Depois, em Project Settings > Domains, adicione seu domínio e siga os registros DNS exibidos pela Vercel.

## Limitações importantes

Este projeto é apenas um protótipo de interface. O login é demonstrativo e não protege contas; o chat usa respostas pré-programadas e não está ligado a um modelo de IA; os registros exibidos são fictícios e não coletam IP, localização ou coordenadas reais. Não use este protótipo para armazenar dados pessoais ou credenciais reais.
